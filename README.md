# SKY

**Draw a line in the sky. A little paper plane flies it.**

The fourth piece after [MEADOW](https://github.com/Mariaareadne1/meadow-interactive), [POND](https://github.com/Mariaareadne1/pond-interactive) and [HIVE](https://github.com/Mariaareadne1/hive-interactive): a painted town on a sheet of paper. Draw anywhere over it and a paper plane folds itself from a square sheet and flies your line — banking into turns, looping where your line loops, its shadow skimming the rooftops — then glides down onto whatever is below.

Work in progress — see `PROGRESS.md`.

```bash
npm install
npm run dev   # http://localhost:5386
```
